### Pinch (pinch-app.com/developers) — tested 4 Nov, key works
- Auth `Authorization: Bearer pk_live_…`; free tier 30/min, 1,000/day; base `https://pinch-app.com/api`.
- Retailers: Woolworths, Coles, ALDI, Harris Farm, Umall (~75,900 products), national online prices, weekly.
- Endpoints used: `/health`, `/account`, `/products/search?q=&retailer=&limit=`, `POST /basket/compare` (items `{query}`), `/specials`.
- **Data quirks to normalise:** Woolworths weight items ("per 200g") return the **per-kg** price as `price` (e.g. salmon $42, extension saw $6.00/200 g) — use cup/unit price; Coles `cup_measure` sometimes "1 g" for per-kg; `/specials` top items are non-food (filter to food categories); freshness flags only in basket results.
- **Terms risk:** free tier only for products free to end users; attribution "Price data by Pinch" + link; no bulk redistribution; basket request contents are logged (send generic item names only); **bans "a competing grocery price comparison service"** — ask Pinch whether So Giá is OK before shipping Pinch prices.

### WhichGrocer (whichgrocer.com/developers/docs, API v2.7.0) — docs read, key not yet tested
- Base `https://api.whichgrocer.com/v2`; auth `Authorization: Bearer wg_live_…` or `X-Api-Key`; backend only. `/health` free.
- Stores: Woolworths, Coles, ALDI, Chemist Warehouse, Priceline, BIG W, Kmart, Bunnings; national catalogue prices, updated ≥ twice a week; `is_stale`, `updated_at`, unit price/measure, 30-day stats.
- Useful: `/products/search` (filters store, category aisle, in_stock_only, max_age_days, sort price/unit_price, group_by_store), `POST /products/search-basket` (≤ 50 lines, 1 credit per line), `/products/{id}/equivalents`, `/product-details?barcode=`, specials, Biggest Savings.
- Plans: Trial $0 (200 credits/month, 1 request per 5 s, personal), Ultra $4.99 (2,000, personal/AI agents), **commercial** Starter $79 (5,000), Growth $249 (25,000).
- Terms (31 Aug 2026): app use allowed incl. paid products; display prices/images/links; caching allowed but don't show old prices as current; no competing data API, no reselling, no keys in client code/extensions; attribution "Product data by WhichGrocer" (+ link); delete cached data within 30 days if access ends.

### Proposed design (needs Henry's plan approval, rule 4)
One server function `grocery-prices` with `pinch.mts` and `whichgrocer.mts` adapters → common shape (retailer, name, size, price, unit price per kg/L/each, was-price, special, captured-at, source). Cache first (Pinch 7 days, WhichGrocer 3 days) → Pinch → WhichGrocer as fallback (Pinch error/over limit/no confident match, or Chemist Warehouse/Priceline items) → if both disagree > ~15% hold for review → circuit breaker per provider → if both fail show last saved price with its date, never invent one. Strict WhichGrocer credit budget (~6/day on trial; basket call for shopping lists). Display: "Giá toàn quốc (online)" fallback under extension store prices in So Giá, shopping list estimate, food-only specials, receipt hint; date + attribution on every price. Studio: per-provider on/off, daily/monthly caps, key status (set/missing only), credits remaining, "Test connection". Tests mock both providers (CI needs no keys).
