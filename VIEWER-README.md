# Studio and house 3D viewer

Open index.html in a WebGL2-capable browser, or enable GitHub Pages from main / root to open it in Safari on a phone. A GitHub file page is not the interactive website.

Final layout: Goddard Street 2308. OC/measured plans supplement compatible measurements only; older layouts are comparison-only. Original source drawing images, presentation images and PDFs are excluded from this repository upload. The property-address heading is removed. The repository name and plan-basis name are not anonymised.

Outside: one-finger orbit, pinch zoom, two-finger pan, tap a room to enter. Inside: drag to look, pinch to change view angle, two-finger move, tap floor to move. Floor buttons and the room selector reach garage, studio and main house. Inspection movement has no collision.

Dimensions with unresolved source conflicts are flagged. Existing house/site and furniture are approximate. This is a review model, not construction/engineering certification. Eighteen programmatic regression checks passed in the full review build; actual GPU/iPhone Safari rendering still needs device testing. The PNG is a software mesh preview.
